# QUANTSMART video tutorials

[Open the Tuttorial folder on Google Drive](https://drive.google.com/drive/folders/1UuT99hkPbe_WvEqsEJ-XyOjl5P-NnLbn). The videos use English synthetic narration and Vietnamese subtitles. The app and repository documentation remain in English.

Follow the numbered lessons: historical CSV import; L1 measurement; L2 context; L3 formula; L4 gate; L5 rules; L6 reference zones; Card import and backtest interpretation; matched entry/exit controls; prompt export and JSON import for each custom layer; strategy authoring briefs; and BEAST composition, role ablation and Card export.

The recordings show the actual local application. Pauses are extended where needed for narration. Included JSON examples demonstrate the import contracts; they are not presented as live responses from an external AI service. Read [the verification scope](LAYER_VALIDATION.md) before interpreting research results.

Every lesson includes Vietnamese captions embedded in the video. Separate English and Vietnamese subtitle files and example definitions accompany the local tutorial package. Watch the videos at full resolution to read the editor and tables.

A BEAST export is an unvalidated Strategy Card. Its saved definition and operating context are preserved. A separate Card backtest is required before interpreting its performance.
